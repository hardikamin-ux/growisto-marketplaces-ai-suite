⚠️ Before you install

Each person must use their own dedicated burner Amazon India account — never your personal account. Create a fresh Gmail address → register on amazon.in → that's your scraper account.

The tool stores your session locally in a .browser_profile folder inside the app directory. Never share this folder with anyone.

How to set up
One-time setup takes about 5 minutes.
Step 1 — Download & extract

Click Download for Mac above. Find the zip in your Downloads folder and double-click to extract it.

Step 2 — Run the installer

Open Terminal. Drag install-mac.command from the extracted folder into the Terminal window, then press Enter.

bash ~/Downloads/amazon-review-scraper-main/install-mac.command

If macOS blocks the file: System Settings → Privacy & Security → click Open Anyway.

Step 3 — Wait for setup

The installer installs Python packages and the Chrome browser (~3–5 minutes). Don't close the Terminal window.

Step 4 — Launch the app

When complete, an Amazon Scraper shortcut appears on your Desktop. Double-click it to open the tool in your browser.

Step 1 — Download & extract

Click Download for Windows above. Right-click the zip → Extract All → choose a folder.

Step 2 — Run the installer

Inside the extracted folder, right-click install-windows.bat → Run as administrator.

If Windows Defender shows a warning: click More info → Run anyway.

Step 3 — Wait for setup

The installer installs Python packages and the Chrome browser (~3–5 minutes). Don't close the Command Prompt window.

Step 4 — Launch the app

When complete, an Amazon Scraper shortcut appears on your Desktop. Double-click it to open the tool in your browser.

After setup — using the scraper

Create a burner account

New Gmail → register on amazon.in. Skip phone/card. Only takes 2 minutes.

One-time only

Find the ASIN

Open the Amazon India product page. The ASIN is the 10-character code after /dp/ in the URL.

Launch the scraper

Double-click Amazon Scraper on your Desktop. Your browser opens automatically.

Paste & scrape

Paste the ASIN, choose a star filter (or keep All stars), and click Scrape.

Sign in (first time only)

Chrome opens for your burner account sign-in. Do it once — session saves forever.

One-time only

Download the Excel

When the scrape completes, click 📥 Download Excel to save the file.
