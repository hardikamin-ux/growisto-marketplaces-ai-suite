Claude Plugin

Amazon Listing Audit (Parent ASIN)

Scores every child variant under an Amazon parent ASIN out of 100 across 6 pillars — Title, Bullets, Description/A+, Images, Keyword Coverage, and Ratings & Reviews. Delivers a consolidated Growisto-branded Excel workbook and PPTX deck: per-variant scoring matrices, a variant × pillar heatmap, shared vs variant-specific fixes, and a family-wide action plan.

Before You Start
Have the Parent ASIN and its child variant ASINs ready (with each one's variation attribute — flavour, size, colour). Claude will guide you through the inputs — you'll also need target keywords and competitor ASINs for benchmarking.
How to Use
1
Open Claude Desktop This plugin runs on Claude Desktop. Open it and make sure you're signed in with your Growisto account.
2
Trigger the Workflow Start a new chat and ask for a parent-level audit — e.g. "Audit this parent ASIN: B0XXXXXXXX" or "Score all variants of this listing". Claude will automatically trigger the parent audit workflow.
3
Answer Claude's Questions Claude will ask for the variant list, keywords, competitor ASINs, and per-variant listing captures. It then scores each variant independently across 6 pillars and rolls up shared vs variant-specific issues at the parent level.
4
Download Your Deliverables Once complete, Claude generates two files — a Growisto-branded Excel workbook with the variant × pillar heatmap and full scoring matrices, and a PPTX deck with one scoring-matrix slide per variant plus a family-wide action plan.
This plugin requires Claude Desktop — it will not work on claude.ai in the browser.
