Claude Plugin

Amazon Listing Generator

End-to-end Amazon listing creation across a 9-step workflow — from marketplace and browse node selection to SEO-optimised titles, bullet points, descriptions, and backend search terms. Includes competitor research, dynamic bullet themes, inline keyword bolding, and formatted Excel delivery.

How to Use
1
Open Claude Go to claude.ai and sign in with your Growisto account.
2
Go to Plugins Navigate to Plugins from the left sidebar or settings menu.
3
Install the Plugin Search for and install Growisto Amazon Listing Generator.
4
Launch the Workflow Start a new chat and type /amazon-listing-generator to begin the 9-step listing workflow.
5
Follow the Prompts Select your marketplace, browse node, and tone. Add product details and receive your fully formatted listing with an Excel export.
This plugin runs entirely inside Claude. No external login or setup required beyond the one-time install.
